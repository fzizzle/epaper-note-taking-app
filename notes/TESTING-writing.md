# Writing screen: owner checklist

About 15 minutes. Use the test copy, **Documents/E-paper Notes test/PWT test copy.pdf**. The app now writes into real files, so don't use an original yet.

Open **E-paper Notes**, then tap the test copy in the list. (If it asks for file access, allow it.)

- [ ] **W1. Writing feel.** Write a few lines with the pen. Is the ink as quick as in Boox Notes? Do lines get thicker when you press harder? After about a second the page redraws: does the ink stay in the same place and look the same?
- [ ] **W2. Highlighter.** Tap **Highlighter** and mark some text. Is it see-through, and can you still read the text? How does the colour look?
- [ ] **W3. Scrolling and zoom.** Scroll with one finger. Pinch with two fingers to zoom in, and pan. Write while zoomed in, then zoom out: is the writing where you put it?
- [ ] **W4. Palm.** Write with your palm resting on the screen. Does the palm draw or move the page?
- [ ] **W5. Safety.** Write 3 strokes, then within 2 seconds open the recent-apps view and swipe the app away. Reopen the file: are all 3 strokes there?
- [ ] **W6. Another viewer.** Leave the app, then open the same file in Boox's own reader. Is your ink there?
- [ ] **W7. Last page.** Go back with ←, open the file again: same page?
- [ ] **W8. Turning the tablet.** Turn the tablet sideways. Does the screen rotate? (It's meant to stay upright.)
- [ ] **W9. Anything odd.** Flicker, slowness, buttons, messages.

Known for now (later plans): button 1 just writes ink, button 2's eraser does nothing yet, and there's no undo.
